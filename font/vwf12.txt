# Yakuman DS English variable-width font, 12 px tall, max 8 px wide.
#
# Format:  "@ <hex byte> [adv=N]"  starts a glyph (the byte value it is drawn for), followed by
#          "<row> <pattern>" lines, row 0 = top. Unlisted rows are blank. '#' = ink, '.' = blank.
#          Width = pattern length (same for every row of a glyph). Advance defaults to width + 1.
# Metrics: caps & ascenders rows 1-9, x-height rows 3-9, baseline under row 9, descenders rows 10-11.
#
# Bytes 0x21 '!', 0x23 '#', 0x3C '<', 0x3E '>' are control codes in the game's renderer, so
# their glyphs live at 0xA1, 0xA3, 0xBC, 0xBE and the text encoder remaps them.
