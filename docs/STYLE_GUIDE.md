# Translation Style Guide

Terminology follows the English client of *Mahjong Soul* wherever a term exists there
(yaku names taken from Mahjong Soul's English yaku table, as mirrored in community tools such
as [killer_mortal_gui](https://github.com/killerducky/killer_mortal_gui/blob/main/translations.js)
and [amae-koromo](https://github.com/SAPikachu/amae-koromo/blob/master/src/locales/en.json)).
Tiles themselves are not translated. Abbreviations are fine when space is tight.

## Text conventions

- Encoding markup: `\n` newline, `{term}` highlighted glossary link, `^` instant-draw toggle.
  Literal `!`, `#`, `<`, `>` are fine (the encoder remaps them).
- Glossary descriptions must keep the same number and order of `{links}` as the Japanese.
- Keep printf specifiers (`%d`, `%2d`, `%s`) identical and in the same order.
- Prefer sentence case for prose, Title Case for menu items and yaku names.
- Japanese ellipses `・・・`/`････` → `...`; 「」 quotes → "…"; 『』 → "…" (or {highlight} if it was a term).
- Wrapped text (dialogs, tutorial, glossary) relies on the engine's word wrap; insert `\n` only
  where the Japanese has a deliberate break (e.g. before "Is that OK?").
